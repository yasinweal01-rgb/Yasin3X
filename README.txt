رحلة ياسين - موقع تطوير الذات

للنشر على GitHub Pages:
1. ارفع ملف index.html إلى مستودع GitHub جديد واجعله في الجذر.
2. افتح Settings > Pages.
3. اختر Deploy from a branch، ثم Branch: main و Folder: /(root)، ثم Save.
4. انتظر اكتمال النشر وافتح الرابط الذي يظهر في صفحة Pages.

تنبيه: الموقع يحفظ التقدم محليًا في المتصفح؛ لا توجد حسابات أو مزامنة بين الأجهزة.
